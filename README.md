# RaceDay — Event Management Platform

## System Description

**RaceDay** is a full-stack web-based event management system for the South African road running, walking, and cycling community.

## Two User Roles

### Organiser
An Organiser is a club, race director, or sports organisation that runs events.
An Organiser can:
- Create, edit, and delete events
- Create and manage event categories
- View all participants enrolled in their events
- Capture and update participant results after the race

### Participant
A Participant is a runner, cyclist, or walker who enters events.
A Participant can:
- Create an account and log in
- Browse all upcoming events
- Enter an event by selecting a category
- View their own enrolment history
- Track their personal race results

## Setup Instructions (SQL Script)

1. Open SQL Server Management Studio (SSMS)
2. Open `docs/raceday_database.sql`
3. Press **F5** to execute the script
4. The `RaceDay` database will be created with all tables and seed data
